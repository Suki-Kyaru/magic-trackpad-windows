# dev.5.4.1 R8 - spacing rhythm decision

The accepted layout rhythm is semantic rather than mechanically symmetric.

## Header group

Treat the wizard page title and description as one header group.

The first primary content should begin after approximately 12 scaled pixels.

## InfoBefore

Hide the redundant click instruction and move the InfoBefore body upward.
Preserve the body's bottom edge.

## Destination

Move only the main destination content group upward by 8 scaled pixels.

Do not move:

- disk-space label;
- bottom bevel / navigation zone;
- Back / Install / Cancel buttons.

## Copy

The destination helper text must reflect the actual R6 flow:

```text
Browse -> Install
浏览 -> 安装
```

Never refer to Next on the final pre-installation page.
