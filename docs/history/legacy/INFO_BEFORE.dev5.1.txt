Magic Trackpad for Windows

这是第一版 x64 安装器预览。

它会：
- 检查 Windows 11 x64 环境；
- 检查已安装的 Magic Trackpad 驱动版本；
- 当前版已安装时直接跳过，不重复写入；
- 未安装时安装项目内固定的 Microsoft 签名上游驱动；
- 安装 Magic Trackpad 控制面板和开始菜单快捷方式。

它不会：
- 自动卸载或清理旧驱动；
- 静默降级较新的驱动；
- 自动处理多个残留驱动包；
- 修改 A3120 的 MI_00 接口；
- 自动配对蓝牙；
- 修改 Windows 三指/四指手势。

当前开发版卸载程序只移除控制面板、文档和快捷方式，驱动会保留。
后续会在独立阶段实现“精确识别后安全卸载驱动”。
