# Initial repository documentation baseline

This patch is intentionally documentation/repository-hygiene only.

It:

- replaces the obsolete early-prototype README;
- documents the real pre-Git development history;
- records the actual v0.1.0-dev.5.1 hardware/installer validation baseline;
- records why Git history begins at dev.5.1;
- adds a repository-hygiene verification script;
- removes the stale root `SHA256SUMS.txt` created for the original starter ZIP.

It does not modify:

- C++;
- PowerShell driver/install logic;
- Inno Setup behavior;
- VERSION;
- staged upstream driver files;
- Driver Store;
- Windows registry;
- Magic Trackpad device state.
